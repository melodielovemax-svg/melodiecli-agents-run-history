# Evidence requirements

No production evidence is included in this scaffold.

For any future implementation or operational claim, retain evidence containing:

- Claim and exact scope.
- Source system and provider reference, where applicable.
- Timestamp and environment.
- Verification status and method.
- Responsible operator or approved service identity.
- Test/build/deployment command and result.
- Integrity hash for exported evidence, where appropriate.

Never record fabricated customers, revenue, payments, balances, transactions,
wallet activity, model availability, or deployment success. Test fixtures must be
isolated and explicitly labeled TEST.

Publication evidence must come from GitHub confirming repository existence;
a local scaffold is not a published repository.
