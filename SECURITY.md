# Security policy

## Current status

This is a planned scaffold. No production service or security support channel
is currently operated from this repository.

## Reporting

Do not disclose sensitive vulnerability details in a public issue. Until a private
reporting channel and responsible owner are configured, do not treat this repository
as accepting security reports or as providing a response-time commitment.

## Requirements before implementation

- Assign a verified owner and private reporting contact.
- Document supported versions and response process.
- Keep credentials out of source, issues, logs, and test fixtures.
- Require review and evidence for security-sensitive changes.
- Financial, wallet-signing, and token operations must require explicit human approval.
